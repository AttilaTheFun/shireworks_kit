- **One renewal at a time across apps sharing a sign-in**: `GitHubCredentials(…, renewalLock:)` takes a `RenewalLock` every app on the store shares (`FileRenewalLock`: an exclusive `flock` on a file in an app group's container, let go by the system if its holder ends). Under it the store is read again, the token renewed, and the renewed token kept before the lock is let go, so two apps never spend one refresh token, and the one that waited takes the other's renewal.
