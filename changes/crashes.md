- ShireworksCrashes, a new capability (and product): the app's crashes caught on the device (Sentry's SDK on iOS and macOS, used on the device alone: no account, nothing sent) and filed as GitHub issues with the shared sign-in, one issue a crash (by its signature), commented on when it happens again and reopened for a newer version; kept and pruned while nobody is signed in (docs/crashes). `ShireworksKit` imports it. GitHubIssues gains `searchIssues` and `IssueRedaction` (Shake's redaction, shared).
