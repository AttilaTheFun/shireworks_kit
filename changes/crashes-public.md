- ShireworksCrashes: in a public repository (or one whose visibility GitHub can't say), a crash's issue leaves out the exception's reason (`(reason left out: public repository)`) and the breadcrumbs, which can carry the user's own words; its title is the exception's type and top frame, and its signature leaves the reason out. Each filing pass asks GitHub whether the repository is private. `ShireworksCrashesPublicDetails` (Info.plist, Boolean) or `CrashesConfiguration.publicDetails` files them anyway (docs/crashes, "Public repositories"). GitHubIssues gains `isPrivate(repository:)`.
