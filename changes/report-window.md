- A request (Help › Report a Bug…, a shake) opens the report once, in the window made key (on iOS, the scene made active) most recently, so `.shakeToReport` can go on every window. For a Mac app whose windows may all be closed (a menu-bar app): `ShakeKitReportWindow(repository:)`, a scene of ShakeKit's own that Help › Report a Bug… opens when no key window carries `.shakeToReport`, and `ShakeKitReportButton`, which does the same from a MenuBarExtra. `NewIssueSheet` takes a `close` action, for where it isn't a sheet.
